# shiftdiff

Shift URLs and diff query parts with stable normalization.

**Site:** https://theworker02.github.io/shiftdiff/

## Install / run

```bash
git clone https://github.com/theworker02/shiftdiff.git
cd shiftdiff
node src/cli.js
node --test
```
